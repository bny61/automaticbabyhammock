# Sketches

Quick visual thinking from brainstorming sessions. Rough by design.

## Formats

- **ASCII diagrams** for mechanical arrangement, load paths and cross-sections — they diff well in
  git and can be edited mid-conversation without a tool
- **Mermaid** for flows, states, decision trees and block structures — renders in the docs site
- **Photographs and hand sketches** are welcome; name them so the subject is obvious

## Naming

`YYYY-MM-DD-subject.md` or `.svg` / `.png`, referenced from the session note that produced it.

## Status

These are not drawings. Manufacturing drawings live in `mechanical/drawings/`, and architecture
diagrams that carry authority live in `docs/02-architecture/`. A sketch here that turns out to
matter should be redrawn there.
